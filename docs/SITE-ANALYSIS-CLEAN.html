Key Correction From Previous Report

CMS ≠ Experiments. They are orthogonal layers that serve fundamentally different purposes and do not compete:

  • CMS (MD-based, file system) → authoring, structure, metadata, versioning, portability. KEEP
  • GrowthBook → feature flags, A/B testing, targeting, rollouts, statistical analysis. ALREADY INTEGRATED

The previous report incorrectly framed the Vue + SQLite experiment tool as a "custom CMS." It was an A/B test harness with a stats engine — not a content management system. The CMS has always been the flat-file / Markdown-based content approach. GrowthBook was never a CMS replacement; it replaces the delivery infrastructure around who sees what and measuring impact.
